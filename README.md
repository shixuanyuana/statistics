# 足球视频数据统计台

一个完全本地运行、无需后端的足球比赛视频人工统计工具。

## 打开方式

直接双击 `index.html`，用 Chrome、Edge 或其他现代浏览器打开即可。

## 使用方法

- 修改顶部两个队名。
- 视频开始时点“开始计时”，结束时点“结束计时”锁定本场数据。
- 每项使用 `+` / `−` 修正数据，数值不会低于 0。
- 每次变动都会记录实际操作时间、视频时间点、队伍、项目、变化量及修改前后数值。
- 导出本场 Excel 后，点击“开始下一场”并确认。新场次的计时、计数和明细从零开始。
- 数字键 `1–7` 依次对应进球、射门、射正、成功传球、角球、任意球和头球。按住 `Shift` 再按数字键给队伍 2 加一。
- 数据会自动保存在当前浏览器中，刷新或关闭页面不会丢失。
- 点击“导出 Excel”，下载含“统计汇总”和“变动明细”两个工作表的 `.xlsx` 文件。

## 扩展统计项目

编辑 `app.js` 顶部的 `STAT_DEFINITIONS` 列表即可添加、删除或调整统计项目。
