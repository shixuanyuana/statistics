# 足球视频数据统计台

一个完全本地运行、无需后端的足球比赛视频人工统计工具。

## 打开方式

直接双击 `index.html`，用 Chrome、Edge 或其他现代浏览器打开即可。

## 使用方法

- 修改顶部两个队名。
- 点击“开始”同步视频计时；空格键也可开始或暂停。
- 每项使用 `+` / `−` 修正数据，数值不会低于 0。
- 数字键 `1–9` 给队伍 1 对应项目加一；按住 `Shift` 再按数字键给队伍 2 加一。
- 数据会自动保存在当前浏览器中，刷新或关闭页面不会丢失。
- 点击“导出 Excel”，下载含“统计汇总”和“操作明细”两个工作表的 `.xlsx` 文件。

## 扩展统计项目

编辑 `app.js` 顶部的 `STAT_DEFINITIONS` 列表即可添加、删除或调整统计项目。
